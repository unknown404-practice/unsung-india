## 2) High‑Level System Description

### 2.1 Core Capabilities

1. **Hero Catalog**
   - Entities: `Hero`, `Contribution`, `TimelineEvent`, `Source`, `MediaAsset`, `Tag` (state, language, domain, era).
   - Fields (minimum): name, name_local, birth_year, death_year, state, languages[], domains[], short_bio, contributions[], image_url, wikipedia_url, other_sources[], is_unsung_reason, created_at, updated_at.
   - Data sources: Wikipedia (MediaWiki API / Wikimedia Enterprise), PIB “Lesser Known Freedom Fighters”, academic lists, Science Reporter, etc.
   - All content stored in our DB with original summaries (to avoid copyright issues), linked to sources.

2. **Public Web App**
   - Pages: Home, Search/Explore, Hero Profile, Banner Preview/Download, About, Contribute/Suggest, Admin (protected).
   - Features:
     - Search by name, state, domain, era.
     - Filters (language, field, time period).
     - Profile: portrait, short bio, key contributions (3–5 bullets), timeline, sources, related heroes.
     - “Generate Banner” button per hero.

3. **Banner Factory**
   - Templates: Roadside billboard, Metro pillar, Bus stop panel, College notice board (A2/A3).
   - Inputs: hero data + language pair + size + color theme.
   - Outputs: PNG/JPG for digital signage, PDF for print.
   - Auto‑layout:
     - Name (largest), 1‑line tagline, 3 bullet contributions, QR code → full profile URL, small source line (e.g., “Sources: Wikipedia / PIB”).
     - Bilingual: Hindi + English (or English + regional).
   - Backend renders banners using a template engine with placeholders.

4. **APIs (Public + Admin)**
   - Public read APIs:
     - `GET /api/heroes` (list, with filters, pagination, search).
     - `GET /api/heroes/:id` (full profile).
     - `GET /api/banners/templates` (list templates).
     - `POST /api/banners/render` (render banner for given hero + template + options).
   - Admin APIs (protected):
     - CRUD for heroes, sources, media, templates.
     - Moderation endpoints for community submissions.

5. **Community & Moderation**
   - “Suggest a Hero” form (name, bio, sources, image upload).
   - Moderation queue: pending → approved/rejected with reason.
   - Version history for hero records.

6. **Integrations (planned / optional)**
   - **Bhashini APIs** for translation (EN ↔ HI and other Indian languages).
   - **Indian Culture Portal (ICP) 2.0** & **Gyan Bharatam National Digital Repository** as potential integration targets (metadata exchange, APIs).
   - Wikimedia APIs for images and links.
