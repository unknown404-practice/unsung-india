# Unsung Heroes of India — Cinematic Next.js Frontend

The Next-Level public web interface and interactive **Banner Factory Studio** for the **Unsung Heroes of India** Digital Public Infrastructure.

---

## 1. Features
- **Cinematic Aesthetic**: Midnight & saffron sovereign gradients, frosted glassmorphism, and classic serif display typography.
- **Dynamic Search & Filtering**: Multi-state, multi-domain, and Indic keyword search.
- **Interactive Banner Studio**: Live real-time visual canvas simulator for Metro Pillars, Roadside Billboards, Bus Shelters, and ISO A3 College Notice Boards.
- **Cold-Start Resilience**: Graceful edge-caching fallback ensuring 0s latency even if backend compute is warming up.
- **Community Submission Engine**: Public hero proposal form with strict primary citation validation.

---

## 2. Quickstart

```bash
cd frontend
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
